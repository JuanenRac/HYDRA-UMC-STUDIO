# Security Policy 🔒 (HYDRA-UMC-STUDIO)

## Reporting a Vulnerability

Security issues in the web dashboard (e.g., **XSS**, **Token Leakage** in local storage, or **CORS** bypass) should be reported privately:

1. **Email**: `electrohobby3d@gmail.com`.
2. **Verification**: Include steps to reproduce the issue in a standard browser (Chrome/Edge).
3. **Safety**: Ensure the vulnerability doesn't allow remote control of hardware without a valid token.
