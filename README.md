# 🚀 Hydra-UMC Studio Robotic Arm Control Interface

Hydra-UMC Studio is a web-based, full-featured control panel designed to monitor and manage up to 8 robotic arms (Parol6, Faze4, Generic) concurrently. It supports assigning tools (e.g. CNC Spindles, Lasers, 3D Print Extruders), moving joints manually, configuring global XY tables, and recording robotic trajectories.

## 🛠️ Features

- **Multi-Robot Dashboard:** Overview of up to 8 robotic arms with online/offline status, current roles, and tools.
- **Virtual Kinematics:** 3D rendering of the robotic arm movements in real-time, showing visual representations of attached tools.
- **Joint Controls:** Granular jogging of individual joints with step sizes from 0.01° to 10.00°.
- **XY Table Configuration:** Fully interactive 3D setup for global XY stages, assignable to specific robots for advanced positioning.
- **Trajectory Management:** Record waypoints, load preset kinematic examples, and export trajectories as JSON.

## 🛠️ Tech Stack

- React 18+ (Vite)
- Tailwind CSS (Styling)
- Three.js / React Three Fiber (3D Kinematics)
- Lucide React (Icons)
- TypeScript
